六件事，會了就夠用

  1. 黑窗左邊那一串字 ＝ 你現在在哪個資料夾。
  2. 打完指令要按 Enter。不按 Enter 什麼都不會發生。

Step 1　開兩個帳號（約 10 分鐘，全程用滑鼠）

先開帳號再裝軟體——帳號要收 email 驗證碼，請務必先做這一步。

GitHub：前往 https://github.com/signup，開好後記下你的使用者名稱。

GitHub 強制要求二階段驗證（2FA）。請在手機上安裝 GitHub Mobile：

  • iOS：App Store 搜尋「GitHub」
  • Android：Google Play 搜尋「GitHub」

安裝後用你剛申請的帳號登入，GitHub 要求設定 2FA 時選 「GitHub Mobile」，按照畫面指示完成。當天用筆電登入 GitHub 時，手機的 GitHub app 會跳出確認通知，按一下就能通過驗證。

Netlify：前往 https://app.netlify.com/signup，選 「Sign up with GitHub」，不要另外設密碼。

為什麼 Netlify 要用 GitHub 登入？因為 Netlify 要自動偵測你的 GitHub repo 並自動部署，兩個帳號連在一起才行。

這些東西到底是什麼

上課中想不起來就翻到這裡。完整版看講者發的《這些東西到底是什麼？》

命令列（黑窗）是什麼

一種用打字操作電腦的方式。你平常用滑鼠點圖示，它換成打字。

滑鼠看圖片菜單用手指點。不用記，但複雜的需求點不出來
打字（CLI）直接跟廚師說「牛肉麵，大碗，不要香菜」。精確、可以複製給別人，但你要知道菜名

它不是比較高級的用法，只是另一種介面。看起來嚇人只因為一片黑、沒有按鈕可以摸索 —— 而今天總共只用到七個指令。

指令怎麼讀（看懂這個就看懂全部）

指令的四個部分
git   commit   -m   "..."
 ^      ^       ^     ^
 1      2       3     4
1 程式名找誰做。git ＝ 找 Git 這個工具
2 子指令做什麼（動詞）。commit ＝ 做一個存檔點
3 選項附加條件。-m ＝ 我要順便寫說明
4 值選項要用的資料。"我的第一個網頁"
  • 用空白分隔，所以內容有空白時要用引號包起來。
  • 一個橫線是縮寫，兩個橫線是全名：-m 和 --message 是同一件事。
  • 一個點 . ＝「這個資料夾」，也常代表「全部」。
  • 想查東西就加 --help，例如 git --help。

Git ≠ GitHub（最常見的誤會）

Git 是相機（一個程式，在你電腦裡，離線也能用）；
GitHub 是雲端相簿（一個網站，幫你把存檔放到網路上）。
你可以只用相機不上傳，但不能沒有相機就有照片。

「我要寫網頁，為什麼要裝 Node.js？」

因為你不是要用它，只是要用它來裝別的東西：

要用 netlify 指令 → 它住在 npm 這個商店裡 → npm 是 Node 附帶的 → 所以要先裝 Node。
今天你不會打任何一行 Node 或 npm 指令。

這四個字要記住：

  • git init　跟電腦說「這個資料夾開始要記錄版本了」。只做一次。
  • git add .　把改動放進紙箱。（. 是「全部」）
  • git commit　封箱、貼標籤。這就是一個存檔點，永遠可以回來。
  • git push　把箱子寄到 GitHub。

為什麼要這麼麻煩？因為有了存檔點，你才敢亂改。

如果黑窗突然變成一個奇怪的編輯器、打字沒反應： 你的 git commit 少了 -m "訊息"。 按 Esc，再打 :q! 按 Enter 就能離開，然後重貼完整那一行。

  </script>

getElementById ＝「幫我找到叫這個名字的東西」。
oninput = function () {...} ＝「當它被拉動的時候，做這件事」。

HTML 是長相，CSS 是化妝，JavaScript 是行為。今天你三個都碰過了。

里程碑 6　改壞了怎麼救

01:17–01:24

  1. 打開 index.html，把整個 <script> 到 </script> 刪掉，存檔。

  3. 看看發生什麼事：
貼到黑窗
git status

紅色的 modified: index.html ＝ Git 知道你動了這個檔案，而且還沒存檔點。

救回來：

貼到黑窗
git restore .

瀏覽器按 Ctrl+F5 → 全部回來了。

記住兩句話就好：

  • 還沒 commit 就改壞 → git restore .
  • 已經 push 才發現壞 → git log --oneline 找代號，git revert 那個代號，再 git push

這就是為什麼前面要一直 commit。存檔點的價值，是讓你有膽子亂改。

已經 push 上去才發現壞了
貼到黑窗
git log --oneline

找到壞掉那次的代號（像 a1b2c3d），把下面的 a1b2c3d 換成你看到的：

改代號後貼上
git revert a1b2c3d
git push
