# 終端機生存卡

> **列印出來，貼在螢幕旁邊。** 課前準備與工作坊當天都會用到。

---

## 這是什麼？

一個**只能用打字操作**的視窗。

你平常用滑鼠雙擊資料夾、拖檔案——做的是同一件事。
終端機只是換成「打字告訴電腦要做什麼」。沒有比較高深，只是沒有按鈕。

它有很多名字，看到哪個都一樣：**終端機／命令列／PowerShell／黑窗**。

---

## 先講最重要的一句

### 你不會弄壞電腦。

今天用到的每一個指令都是安全的。
**錯誤訊息不是你的錯，也不代表壞掉。** 紅色的字只是電腦在跟你講話。

會出錯是正常的。全場每個人都會出錯，包括講者。

---

## 怎麼打開（而且是在對的資料夾裡）

**不要**從開始選單找 PowerShell——那樣打開會在錯誤的位置，你會迷路。

正確做法：先用滑鼠進到你的專案資料夾，然後在**空白處**按右鍵。

| 你的系統 | 做法 |
|---|---|
| Windows 11 | 空白處**右鍵** → 「**在終端中開啟**」 |
| Windows 10 | 空白處 **Shift + 右鍵** → 「在此處開啟 PowerShell 視窗」 |
| 都找不到 | 檔案總管上方的**網址欄**，把整串路徑刪掉，打 `powershell` 按 Enter |

這個方法讓你**永遠不用打 `cd`**，也不會迷路。

---

## 六件事，會了就夠用

**1. 左邊那一串字 = 你現在在哪個資料夾**

```
PS C:\Users\你的名字\Desktop\my-first-page>
                                         ↑ 游標在這裡等你打字
```

如果左邊那串不是你的專案資料夾，關掉視窗，用上面的右鍵方法重開。

**2. 打完指令要按 Enter。不按 Enter，什麼都不會發生。**

**3. 貼上是按【滑鼠右鍵】，不是 Ctrl+V。**

這是今天最實用的一招。長的指令不要用手打，複製後在黑窗裡按右鍵就貼上了。
（有些新版視窗 Ctrl+V 也可以。右鍵是兩種都通的做法。）

**4. 按【↑】方向鍵，叫回上一個指令。**

打錯字不用整行重打。按 ↑ 把指令叫回來，改掉錯的那個字，再 Enter。

**5. 想停下來：按 Ctrl+C。**

指令跑到一半不想跑了、或卡住太久，Ctrl+C 就中斷。這也是安全的。

**6. 看不懂的字不用看懂。只找三樣東西：**

- 有沒有出現**你的名字或你的網址** → 通常代表成功
- 有沒有 `error` 或 `not recognized` → 有的話**整段截圖**問旁邊的人
- 有沒有叫你**做某件事** → 照著做

---

## 最常見的三個誤會

| 你以為 | 其實 |
|---|---|
| 沒反應，壞了 | 有些指令要等 10–30 秒。**游標在閃就是在做事**，不要一直按 Enter |
| 出現紅字，我完蛋了 | 紅字通常只是告訴你「少了什麼」，照著補就好 |
| 打錯字，要重開電腦 | 按 ↑ 改一個字再 Enter |

還有一個：**打密碼的時候畫面不會動**。那是正常的安全設計，不是沒吃到你的字，照打完按 Enter。

## 今天全部會用到的指令，就這幾個

| 指令 | 白話 |
|---|---|
| `notepad index.html` | 用記事本開這個檔案（沒有就問你要不要建立） |
| `start index.html` | 用瀏覽器打開這個檔案 |
| `git add .` | 把改動放進紙箱 |
| `git commit -m "說明"` | 封箱貼標籤（存檔點） |
| `git push` | 把箱子寄到 GitHub |
| `git status` | 我現在有哪些東西還沒存檔？ |
| `git restore .` | 改壞了，全部回到上一個存檔點 |

沒有別的了。**七個指令，就是今天的全部。**

---

## 卡住的順序

1. 按 ↑ 看看是不是打錯字
2. 看左邊那串字，確認自己在對的資料夾
3. 問旁邊的人（你的 buddy）
4. 翻紅牌
5. 講者說「用追進度包」時，就照做，不要留在原地
